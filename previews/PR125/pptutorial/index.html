Run Optimization Problems from pandapower

Now, by using PandaModels, pandapower has an interface to PowerModels.jl, also pandapower's users has access to some extra optimization models, e.g. some reactive power optimization models are callable directly in pandapower.

The tutorial for the application of each optimization model is available in pandapower repository:

Functions from PowerModels:

  • Power Flow
  • Optimal Power Flow
  • Optimal Transmission Switching
  • Transmission Network Expansion Planning
  • Storage Optimization

Functions from PandaModels:

  • Reactive Power Optimization - maintaining voltage setpoints
  • Reactive Power Optimization - maintaining reactive power setpoints
  • Reactive Power Optimization - active power loss reduction
  • Reactive Power Optimization - branch loading reduction
